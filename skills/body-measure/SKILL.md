# 身体尺寸录入

用户报几个围度，写进去。**只记他报的那几项，不要追问缺的。**

## 字段（全部可空）

| 键 | 中文 | 单位 |
|---|---|---|
| `waist` | 腰围 | cm |
| `hip` | 臀围 | cm |
| `chest` | 胸围 | cm |
| `bicep` | 大臂围 | cm |
| `thigh` | 大腿围 | cm |
| `calf` | 小腿围 | cm |

单位固定 **cm**。用户说"88"就是 88 cm，不要反问单位，
也不要把"1 米 1"这种换算成 110（他自己会说清楚）。

## 数据落地位置

- 数据库：`~/project/private-copilot/data/copilot.db`
- 写入脚本：`~/project/private-copilot/scripts/validate.py`

**不要直接写 SQL。** 走脚本，它会做范围校验和审计留痕。

## 执行步骤

1. **取日期**。用户没说就**用今天**（问日期很烦人）。
   但如果用户说"上周三量的""月初量的"，**必须用他说的日期**。

2. **写入**：

   ```bash
   python3 ~/project/private-copilot/scripts/validate.py body --json '{
     "measured_at": "2026-10-01",
     "waist": 113, "hip": 113, "chest": 107,
     "bicep": 36, "thigh": 58, "calf": 39
   }'
   ```

   **只报了几项就只写几项**，不要为了"填满"而编造其他值。
   中文键名也认（`"腰围": 113`），但优先用英文键。

3. **回复**：

   ```
   已记录 ✅ (id=1)
   腰围 113 · 臀围 113 · 胸围 107 · 大臂 36 · 大腿 58 · 小腿 39
   ```

   如果返回 `action: "update"`（同一天已记过），改成：

   ```
   已更新 ✅ (id=1) 今天的围度
   ```

## 硬性规则

- **缺项存 NULL，绝不补 0。** 没量的项就是没量，填 0 会让趋势图断崖。
- **不要追问缺的项。** 这是"随手记"的场景，追问会让人不想用。
- **同一天重复上报 = 局部合并。** 脚本只更新本次给出的项，
  之前记过的其他围度**保持原值**（已验证）。所以用户上午报腰围、
  下午报大腿围，最后一天能凑齐，不会互相覆盖。
- **数值超范围会被拒**（<10 或 >300 cm）。被拒时**不要自己改数字硬塞**，
  原样问用户"这个数看着像单位错了，是 88 cm 吗？"
- **时间缺失会被拒**（和食物记录不同）。补上日期再写。

## 查询趋势

```bash
python3 ~/project/private-copilot/scripts/query.py body --from 2026-01-01 --to 2026-12-31
```

返回里每行带：

- `delta`：相对**上一次**的变化量（缺项不参与比较）
- `whr`：腰臀比（腰围和臀围都有值时才给）
- `compare`：区间首尾两次的对比

用户问"我的腰围怎么变的"时，**按时间顺序列出来**，并指出变化方向和幅度：

```
腰围变化（2026-07 → 2026-10）：
- 07-01  95.0 cm
- 08-01  93.0 cm  (-2.0)
- 10-01  91.0 cm  (-2.0)

累计 -4.0 cm，持续下降。
```

### 趋势分析的注意事项

- **缺项不参与对比。** 只说确实有数据的项，不要拿 NULL 当 0 算出"降了 113cm"。
- **不要下医学结论。** 可以说"腰围涨了 3cm""腰臀比 1.0 偏高"，
  但**不要诊断**或建议治疗。需要判断时提示咨询医生。
- 样本少（只有 1-2 次测量）时**不要谈趋势**，只报当前值。

## 与其他技能的边界

| 场景 | 走哪个 |
|---|---|
| 腰围/臀围/胸围/臂围/腿围（卷尺量的） | `body-measure`（本技能） |
| 体重、血压、血糖、血脂、化验单 | `health-report` |
| 买了体重秤/卷尺的消费 | `expense-capture` |
| 吃了什么 | `food-capture` |

一张图上同时有体重和围度 → **体重走 `health-report`，围度走本技能**，
两边都记，并在回复里说明。
