# 财务总览快照

每个时点一行，记录全部账户余额。用于看资产与负债随时间的变化。

## 字段

**资产类**（填余额，正数）

| 字段 | 含义 |
|---|---|
| `alipay` | 支付宝余额 |
| `wechat` | 微信余额 |
| `bank_balance` | 银行卡余额 |
| `cash` | 现金总额 |
| `wealth` | 理财（基金、股票、定期等） |
| `housing_fund` | 住房公积金 |

**负债类**（**填正数表示欠多少**，不要填负数）

| 字段 | 含义 |
|---|---|
| `huabei` | 花呗 |
| `jd_baitiao` | 京东白条 |
| `credit_card` | 信用卡（待还） |
| `loan_outstanding` | 贷款待还总额 |

**自动计算**（不要手工传，脚本会算）

- `total_assets` 资产总计 = 六项资产之和
- `total_debt` 负债总计 = 四项负债之和
- `net_worth` 净资产 = 资产总计 − 负债总计

## 两个录入方式

| 方式 | 场景 |
|---|---|
| **打字** | "支付宝 1500，微信 300，银行卡 5 万，理财 8 万" |
| **截图** | 发来支付宝/微信/银行 App 的余额页面截图 |

## 写入规则（重要）

```bash
python3 ~/project/private-copilot/scripts/validate.py finance --json '{
  "snapshot_at": "2026-09-30",
  "alipay": 1500,
  "wechat": 300,
  "bank_balance": 50000,
  "cash": 500,
  "wealth": 80000,
  "housing_fund": 45000,
  "huabei": 2300,
  "jd_baitiao": 800,
  "credit_card": 5600,
  "loan_outstanding": 120000,
  "source": "text"
}'
```

### 三条关键规则

**① 只传用户实际说到的字段。**

脚本对**同一天**的重复提交做**部分更新**——只覆盖你传的字段，其余保持原值。所以：

- 用户说"支付宝余额改成 2000" → 只传 `alipay`，其他账户不会被清零 ✅
- **不要**为了"补全"把没提到的字段填 0 —— 那会把已有数据抹掉 ❌

**② 新建快照时，未传的字段默认为 0。**

第一次记录某天时，如果用户只说了一部分账户，其余会记 0。所以你**应该主动问全**：

> "还有哪些账户要一起记吗？（银行卡、理财、公积金、花呗、信用卡、贷款）"

或者至少提醒用户："这次只记了支付宝和微信，其他账户按 0 计入了。"

**③ 负债填正数。**

用户说"信用卡欠 5600" → `credit_card: 5600`。**不要填 -5600**，脚本会拒绝负数。

### 退出码

| 码 | 含义 | 你做什么 |
|---|---|---|
| 0 | 成功 | 回报资产/负债/净资产；`action` 为 `update` 时说明是更新了已有快照 |
| 1 | 校验失败 | 看 `error`，通常是负数或时间格式 |

## 时间

`snapshot_at` 用**快照时点**，通常精确到日（如 `2026-09-30`）。脚本只取日期部分。

用户没说时间时，默认**今天**（这是允许默认时间的场景）。

## 查询

```bash
# 快照列表 + 相邻两期变化
python3 ~/project/private-copilot/scripts/query.py finance --limit 12
```

返回包含 `change` 字段（最新两期的资产/负债/净资产增减）。

自定义查询用只读 SQL：

```bash
python3 ~/project/private-copilot/scripts/query.py sql --q \
  "select snapshot_at, total_assets, total_debt, net_worth
   from finance_snapshots order by snapshot_at"
```

## 回复格式

记账后：

```
已记录 2026-09-30 财务快照 ✅
资产总计：¥177,300.00
负债总计：¥128,700.00
净资产：¥48,600.00
```

问数时，**先给结论再给拆解**：

```
截至 2026-10-31，净资产 ¥87,000.00
较上月 +¥38,400.00

资产：¥87,000.00
负债：¥0.00
```

变化明显时可以说一句趋势（"净资产连续两月上升"），但**不要做投资建议**。

## 与其他技能的边界

- **单笔消费** → `expense-capture`
- **账户余额总览** → 本技能
- 一张图上同时有余额和消费明细 → 问用户要记哪个
